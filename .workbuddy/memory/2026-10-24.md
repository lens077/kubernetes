## Pangolin / Newt 全量升级（SSH config 内除 node0、node6 外全部）

**结果**：全部完成并验证通过。Pangolin 服务端 → **1.25.3**，newt 客户端 → **1.19.0**。

### 关键结论（重要，别再踩）

1. **Pangolin 与 newt 是两条独立版本线**。1.25.3 只是服务端版本号；
   newt 没有 1.25.3，与 1.25.x 配套的最新客户端是 **1.19.0**。
   Gerbil 1.5.2、Traefik v3.7.12 当时已是最新，未动。
2. **只升服务端不升客户端**，服务端日志会刷
   `[warn]: Newt ping with outdated config version: 2 (current: 0)`。
   本次把 k8s 内那个也升到 1.19.0 后告警消失。
3. **Badger 必须留在 v1.7.0** —— 上游明确警告 v1.8.0 坏了（过不了 Traefik 插件完整性校验，
   插件被禁 → 全路由 404）。Pangolin 1.25 启动时**会尝试自动改写 Traefik 配置里的 Badger 版本**，
   但只在配置与默认安装器模板一致时生效，改不动则静默失败。
   本集群 traefik_config.yml 已深度定制（vendored plugins-local + localPlugins + crowdsec/safeline），
   所以自动改写没触发 —— 但这是「碰巧安全」，**每次升服务端前都要 grep 复核**。
4. **升服务端必然断隧道几秒**，客户端报 502 后自愈。**不要手动重启客户端**。
5. **schema 迁移后不可降级**（官方文档明说），升级前必须自己备份 DB。
