# 告警定位设计约定

## 范围

扩展当前 Grafana 告警页，不替换 Grafana 的界面体系。不执行备份、恢复、删除、静音或凭据变更。

## Direction contract

- **THESIS**：当前页先回答「什么问题、哪个对象、怎么核实」，不再让内部标签表承担诊断入口。
- **OWN-WORLD**：继承 Grafana 暗色、原生表格、统计卡和链接；颜色只表达告警级别与状态。
- **STORY**：读取 vmalert 的实际 annotations、labels、activeAt 和表达式；区分原始告警与持续提醒，点击问题携带实例、对象与时间窗进入证据面板。
- **FIRST VIEWPORT**：概要统计之后立即显示全宽问题表；问题摘要、对象、持续时间、下一步和直接入口可读，吞吐曲线退到问题之后。
- **FORM**：现有 Operate 界面的局部扩展；告警页 + 基础设施入口 + CNPG、Kubernetes、CDC、采集/网络证据页。不创建新的视觉世界。
- **FINISH**：以真实浏览器验证列表、长文案、实例跳转、筛选、返回和无错误状态；保存桌面与移动证据，完成只读审阅及文档更新。

## 数据与缺失语义

- Prometheus `ALERTS` 用于数量与历史，不携带 annotations。详情直接读取 vmalert API，不把正文写入指标标签。
- 实时列表不提供已消失实例的历史正文；实例不在列表时明确说明「可能恢复或规则已移除」，不冒充历史回放。
- 页面只解释可核实的观测。备份 timestamp=0 显示「无可用备份」，不换算成年龄；无指标显示缺失，不补成健康。
- 下钻目标使用已有 Grafana 域名与本地 dashboard UID，URL 编码对象值。不链接到手机不可达的 `.dev.test`。
- 保留 current source/refreshtime 与数据来源说明，未采集的宿主资源、备份对象状态等明确列出缺口。
